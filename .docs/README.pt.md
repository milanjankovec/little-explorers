# little-explorers

![Fichas para o pré-escolar com um labirinto, estrelas para contar e pontos para ligar, ao lado de lápis de cor.](little-explorers-cover.png)

little-explorers é uma coleção de código aberto com 64 jogos e fichas para imprimir, destinada a crianças dos 3 aos 5 anos. As atividades estão disponíveis em 23 línguas e são apresentadas sem publicidade. O inglês é a língua predefinida.

**[Demonstração em português no GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=pt)**

## Escolher, gerar e imprimir uma ficha

1. Escolha uma atividade e uma língua. Utilize o rato ou o ecrã tátil para interagir com os controlos no navegador.
2. Selecione **Novos exercícios** ou o botão equivalente da atividade para gerar uma nova ficha.
3. Selecione **Imprimir a ficha** ou **Imprimir os jogos**, escolha o formato A4 com orientação vertical e imprima ou guarde a ficha em PDF. As crianças resolvem as atividades em papel.

## Utilizar sem ligação à Internet

Descarregue e extraia o ficheiro ZIP do repositório ou clone o repositório com Git. Na pasta resultante, abra [index.html](../index.html) num navegador. Cada atividade inclui os seus próprios estilos CSS, código JavaScript e ilustrações SVG. Pode gerar e imprimir as fichas sem instalar programas nem iniciar um servidor web.
