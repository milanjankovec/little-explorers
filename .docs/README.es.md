# little-explorers

![Fichas para preescolar con un laberinto, estrellas para contar y puntos para unir, junto a lápices de colores.](little-explorers-cover.png)

little-explorers es una colección de código abierto con 64 juegos y fichas imprimibles para niños de 3 a 5 años. Las actividades están disponibles en 23 idiomas y se ofrecen sin publicidad. El inglés es el idioma predeterminado.

**[Demostración en español en GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=es)**

## Elegir, generar e imprimir una ficha

1. Elige una actividad y un idioma. Usa el ratón o la pantalla táctil para manejar los controles del navegador.
2. Pulsa **Nuevos ejercicios** o el botón equivalente de la actividad para generar una ficha nueva.
3. Selecciona **Imprimir la ficha** o **Imprimir los juegos**, elige el formato A4 en orientación vertical e imprime o guarda la ficha en PDF. Los niños resuelven las actividades en papel.

## Usar sin conexión

Descarga y descomprime el archivo ZIP del repositorio o clónalo con Git. Abre [index.html](../index.html) en el navegador desde la carpeta obtenida. Cada actividad incorpora sus propios estilos CSS, código JavaScript e ilustraciones SVG. Puedes generar e imprimir fichas sin instalar nada ni iniciar un servidor web.
