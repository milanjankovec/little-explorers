# little-explorers

![迷路、星の数を数える問題、点つなぎの絵、色えんぴつが並ぶ幼児向けワークシート。](little-explorers-cover.png)

little-explorers は、3〜5歳の子ども向けに、印刷して遊べる64種類のゲームとワークシートを集めたオープンソースのプロジェクトです。広告はなく、英語を初期設定として23言語で利用できます。

**[GitHub Pages で試す](https://milanjankovec.github.io/little-explorers/?lang=ja)**

## 選ぶ・作る・印刷する

1. 遊びたいゲームと言語を選びます。ブラウザーの操作にはマウスまたはタッチ画面を使えます。
2. **新しい…** ボタンで新しいワークシートを作ります。
3. **ワークシートを印刷** または **ゲームを印刷** を選び、用紙をA4の縦向きに設定して、印刷するかPDFとして保存します。子どもは紙の上で遊びます。

## オフラインで使う

リポジトリをZIPファイルとしてダウンロードして展開するか、Gitでクローンします。展開またはクローンしたフォルダー内の [index.html](../index.html) をブラウザーで開きます。各ゲームにはCSS、JavaScript、SVG画像が組み込まれています。ソフトウェアのインストールやウェブサーバーの起動なしでワークシートを作成し、印刷できます。
