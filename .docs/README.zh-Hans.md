# little-explorers

![幼儿练习单和几支彩色铅笔。练习单上有迷宫、数星星和连点图。](little-explorers-cover.png)

little-explorers 是一套面向 3 至 5 岁儿童的开放源代码资源，包含 64 个可打印游戏和练习单。所有活动均无广告，支持 23 种语言，默认使用英语。

**[在 GitHub Pages 上体验](https://milanjankovec.github.io/little-explorers/?lang=zh-Hans)**

## 选择、生成和打印

1. 选择一个活动和一种语言。用鼠标或触摸屏操作浏览器里的控件。
2. 点击 **换一组** 按钮生成新的练习单。
3. 选择 **打印练习单** 或 **打印游戏**，将纸张设为 A4 纵向，再打印或存为 PDF。孩子可以在纸上完成活动。

- **数数与大小** — 数一数，圈出数字 · 按数字画圆点 · 找一找，数一数 · 比大小 · 更多、更少还是一样多 · 平均分一分 · 用积木测量 · 图画统计图 · 小商店 · 骰子赛跑 · 加一加，减一减 · 让天平平衡
- **逻辑与观察** — 补全图案规律 · 哪个不属于这一组？ · 分到不同篮子里 · 找影子 · 图上少了什么？ · 剪卡片，找对子 · 找出一模一样的图片 · 哪两个是一对？ · 什么先发生？ · 图案多米诺 · 图形数独 · 找到小熊 · 图案宾果 · 你会有什么感受？ · 记住格子 · 同时满足两条规则 · 看天气选衣服 · 图画密码 · 会浮还是会沉？ · 从上面看 · 摸一摸，找一找

## 离线使用

下载并解压项目的 ZIP 文件，或用 Git 克隆仓库。用浏览器打开解压或克隆目录中的 [index.html](../index.html)。每个活动都内嵌了自身所需的 CSS、JavaScript 和 SVG 图形。打开之后就可以生成并打印练习单。
