# little-explorers

![Pracovní listy pro předškoláky s bludištěm, počítáním hvězdiček a spojováním teček. Vedle leží pastelky.](little-explorers-cover.png)

little-explorers je sbírka 64 her a pracovních listů k vytištění pro děti od 3 do 5 let. Má otevřený zdrojový kód a je bez reklam. Aktivity jsou dostupné v 23 jazycích. Výchozím jazykem je angličtina.

**[Živá ukázka na GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=cs)**

## Výběr, nové zadání a tisk

1. Vyberte aktivitu a jazyk. Ovládací prvky prohlížeče můžete používat myší i dotykem.
2. Tlačítkem **Nové…** vygenerujete nový pracovní list.
3. Klikněte na **Vytisknout list** nebo **Vytisknout hry**. Vyberte formát A4 na výšku a list vytiskněte nebo uložte jako PDF. Děti řeší úlohy na papíře.

## Použití bez internetu

Stáhněte a rozbalte archiv ZIP repozitáře nebo repozitář naklonujte pomocí Gitu. V rozbalené nebo naklonované složce otevřete [index.html](../index.html) v prohlížeči. Každá aktivita obsahuje vlastní CSS, JavaScript a grafiku SVG. Pracovní listy můžete vytvářet a tisknout bez instalace i bez webového serveru.
