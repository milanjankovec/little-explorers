# little-explorers

![Φύλλα εργασίας για παιδιά προσχολικής ηλικίας με λαβύρινθο, αστέρια για μέτρημα και τελείες για σύνδεση. Δίπλα, ξυλομπογιές.](little-explorers-cover.png)

Το little-explorers είναι μια συλλογή ανοιχτού κώδικα με 64 εκτυπώσιμα παιχνίδια και φύλλα εργασίας για παιδιά ηλικίας 3 έως 5 ετών. Οι δραστηριότητες διατίθενται σε 23 γλώσσες χωρίς διαφημίσεις. Η προεπιλεγμένη γλώσσα είναι τα αγγλικά.

**[Online δοκιμή στο GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=el)**

## Επιλογή, δημιουργία και εκτύπωση

1. Επιλέξτε δραστηριότητα και γλώσσα. Μπορείτε να χειριστείτε τα κουμπιά της σελίδας με το ποντίκι ή την οθόνη αφής.
2. Πατήστε το κουμπί δημιουργίας νέων ασκήσεων για να δημιουργήσετε ένα νέο φύλλο εργασίας.
3. Επιλέξτε **Εκτύπωση φύλλου** ή **Εκτύπωση παιχνιδιών**. Ορίστε μέγεθος A4 και κατακόρυφο προσανατολισμό. Εκτυπώστε το φύλλο ή αποθηκεύστε το ως PDF. Τα παιδιά λύνουν τις ασκήσεις στο χαρτί.

## Χρήση χωρίς σύνδεση στο διαδίκτυο

Κατεβάστε και αποσυμπιέστε το αρχείο ZIP του αποθετηρίου ή κλωνοποιήστε το αποθετήριο με το Git. Ανοίξτε το [index.html](../index.html) από αυτόν τον φάκελο στο πρόγραμμα περιήγησης. Κάθε δραστηριότητα ενσωματώνει τα δικά της CSS, JavaScript και γραφικά SVG. Μπορείτε να δημιουργήσετε και να εκτυπώσετε φύλλα εργασίας χωρίς εγκατάσταση ή εκκίνηση διακομιστή ιστού.
