# little-explorers

![Робочі аркуші для дошкільнят із лабіринтом, зірочками для лічби й крапками для з’єднання. Поруч кольорові олівці.](little-explorers-cover.png)

little-explorers — це збірка з відкритим кодом для дітей віком від 3 до 5 років. У ній 64 гри й робочі аркуші, які можна роздрукувати. Завдання доступні 23 мовами й не містять реклами. Мова за замовчуванням — англійська.

**[Онлайн-демонстрація на GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=uk)**

## Вибір, створення й друк

1. Виберіть завдання й мову. Користуйтеся елементами керування в браузері за допомогою миші або сенсорного екрана.
2. Натисніть кнопку **Нові…**, щоб створити новий робочий аркуш.
3. Виберіть **Друк завдання** або **Друк ігор**. Установіть формат A4 і книжкову орієнтацію, а потім надрукуйте аркуш або збережіть його як PDF. Діти виконують завдання на папері.

## Використання без інтернету

Завантажте й розпакуйте ZIP-архів репозиторію або клонуйте репозиторій за допомогою Git. Відкрийте файл [index.html](../index.html) із цієї папки в браузері. Кожне завдання містить власні стилі CSS, код JavaScript і зображення SVG. Щоб створювати й друкувати аркуші, нічого не потрібно встановлювати або запускати вебсервер.
