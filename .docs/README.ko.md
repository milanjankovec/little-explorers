# little-explorers

![미로, 별 개수 세기, 점 잇기 그림, 색연필이 놓인 유아용 활동지.](little-explorers-cover.png)

little-explorers는 3~5세 어린이가 인쇄해서 즐길 수 있는 놀이와 활동지 64종을 모은 오픈 소스 프로젝트입니다. 광고 없이 23개 언어로 이용할 수 있으며 기본 언어는 영어입니다.

**[GitHub Pages에서 체험하기](https://milanjankovec.github.io/little-explorers/?lang=ko)**

## 고르고, 만들고, 인쇄하기

1. 놀이와 언어를 고릅니다. 마우스나 터치 화면으로 브라우저를 조작합니다.
2. **새 …** 버튼을 눌러 새 활동지를 만듭니다.
3. **활동지 인쇄** 또는 **놀이 인쇄**를 선택합니다. 용지를 A4 세로 방향으로 설정한 뒤 인쇄하거나 PDF로 저장합니다. 어린이는 종이 위에서 놀이를 합니다.

## 오프라인 사용

저장소를 ZIP 파일로 내려받아 압축을 풀거나 Git으로 복제합니다. 해당 폴더에서 [index.html](../index.html)을 브라우저로 엽니다. 각 놀이에 CSS, JavaScript, SVG 그림이 포함되어 있습니다. 프로그램을 설치하거나 웹 서버를 실행할 필요 없이 활동지를 만들고 인쇄할 수 있습니다.
