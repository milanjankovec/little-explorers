# little-explorers

![Karty pracy dla przedszkolaków z labiryntem, gwiazdkami do policzenia i kropkami do połączenia. Obok leżą kolorowe kredki.](little-explorers-cover.png)

little-explorers to zestaw 64 gier i kart pracy do wydrukowania dla dzieci w wieku od 3 do 5 lat. Projekt ma otwarty kod źródłowy, jest dostępny w 23 językach i nie zawiera reklam. Domyślnym językiem jest angielski.

**[Wersja demonstracyjna na GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=pl)**

## Wybieranie, tworzenie i drukowanie

1. Wybierz aktywność i język. Przyciski w przeglądarce można obsługiwać myszą lub dotykiem.
2. Użyj przycisku tworzenia nowych zadań, aby wygenerować nową kartę pracy.
3. Kliknij **Drukuj kartę** lub **Drukuj gry**. Wybierz format A4 i orientację pionową, po czym wydrukuj kartę lub zapisz ją jako PDF. Dzieci rozwiązują zadania na papierze.

## Korzystanie bez internetu

Pobierz i rozpakuj archiwum ZIP repozytorium albo sklonuj repozytorium za pomocą Gita. Otwórz plik [index.html](../index.html) z otrzymanego folderu w przeglądarce. Każda aktywność zawiera własny CSS, JavaScript i grafikę SVG. Karty pracy można tworzyć i drukować bez instalowania dodatkowych programów ani uruchamiania serwera WWW.
