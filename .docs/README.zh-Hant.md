# little-explorers

![幼兒學習單和幾支彩色鉛筆。學習單上有迷宮、數星星和連點圖。](little-explorers-cover.png)

little-explorers 是一套為 3 至 5 歲兒童設計的開放原始碼資源，包含 64 個可列印的遊戲和學習單。所有活動均無廣告，支援 23 種語言，預設為英語。

**[在 GitHub Pages 上試玩](https://milanjankovec.github.io/little-explorers/?lang=zh-Hant)**

## 選擇、產生和列印

1. 選擇一個活動和一種語言。使用滑鼠或觸控螢幕操作瀏覽器上的按鈕。
2. 點選 **換一組** 按鈕，就能產生新的學習單。
3. 選擇 **列印學習單** 或 **列印遊戲**，將紙張設為 A4 直向，再列印或儲存為 PDF。孩子可以在紙上完成活動。

## 離線使用

下載並解壓縮專案的 ZIP 檔，或使用 Git 複製儲存庫。從解壓縮或複製的資料夾中，用瀏覽器開啟 [index.html](../index.html)。每個活動都內嵌所需的 CSS、JavaScript 和 SVG 圖形。開啟後即可產生及列印學習單。
