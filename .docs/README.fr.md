# little-explorers

![Fiches de maternelle avec un labyrinthe, des étoiles à compter et des points à relier, à côté de crayons de couleur.](little-explorers-cover.png)

little-explorers est une collection open source de 64 jeux et fiches d’activités à imprimer pour les enfants de 3 à 5 ans. Les activités sont sans publicité et disponibles en 23 langues. L’anglais est la langue par défaut.

**[Démo en français sur GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=fr)**

## Choisir, générer et imprimer une fiche

1. Choisissez une activité et une langue. Utilisez la souris ou l’écran tactile pour actionner les commandes dans le navigateur.
2. Cliquez sur **Nouveaux exercices** ou sur le bouton équivalent de l’activité pour générer une nouvelle fiche.
3. Sélectionnez **Imprimer la fiche** ou **Imprimer les jeux**, choisissez le format A4 en orientation portrait, puis imprimez ou enregistrez la fiche au format PDF. Les enfants font les activités sur papier.

## Utiliser les activités hors ligne

Téléchargez et décompressez l’archive ZIP du dépôt ou clonez le dépôt avec Git. Ouvrez le fichier [index.html](../index.html) du dossier obtenu dans un navigateur. Chaque activité intègre ses propres styles CSS, scripts JavaScript et illustrations SVG. Vous pouvez générer et imprimer les fiches sans installation ni serveur web.
