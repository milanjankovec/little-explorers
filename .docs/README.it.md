# little-explorers

![Schede per bambini in età prescolare con un labirinto, stelle da contare e puntini da unire, accanto a matite colorate.](little-explorers-cover.png)

little-explorers è una raccolta open source di 64 giochi e schede stampabili per bambini dai 3 ai 5 anni. Le attività sono senza pubblicità e disponibili in 23 lingue. L’inglese è la lingua predefinita.

**[Dimostrazione in italiano su GitHub Pages](https://milanjankovec.github.io/little-explorers/?lang=it)**

## Scegliere, generare e stampare una scheda

1. Scegli un’attività e una lingua. Usa il mouse o il touchscreen per interagire con i comandi del browser.
2. Usa **Nuovi esercizi** o il pulsante equivalente dell’attività per generare una nuova scheda.
3. Seleziona **Stampa la scheda** o **Stampa i giochi**, scegli il formato A4 con orientamento verticale e stampa o salva la scheda in PDF. I bambini svolgono le attività su carta.

## Usare le attività offline

Scarica ed estrai l’archivio ZIP del repository oppure clona il repository con Git. Apri nel browser il file [index.html](../index.html) nella cartella ottenuta. Ogni attività include stili CSS, codice JavaScript e illustrazioni SVG. Puoi generare e stampare le schede senza installare software o avviare un server web.
